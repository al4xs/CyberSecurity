# Matemática para Computação

> Conteúdos complementares para expandir conhecimentos matemáticos relacionados à Computação.

Esta seção não faz parte necessariamente da trilha principal de estudos.

Seu objetivo é servir como **biblioteca de aprofundamento**, permitindo consultar ou estudar determinados assuntos conforme a necessidade, interesse ou área da Computação explorada.

---

## 🎯 Objetivo

A matemática possui aplicações diferentes dentro da Computação.

Dependendo da área, determinados conhecimentos podem ser úteis para compreender melhor os fundamentos por trás de:

- 🔐 Criptografia
    
- ⚙️ Algoritmos
    
- 🧠 Inteligência Artificial
    
- 🤖 Machine Learning
    
- 🖼️ Computação Gráfica
    
- 🌐 Redes e Grafos
    
- 📊 Ciência de Dados
    
- 🛡️ Segurança da Informação
    
- 🧮 Teoria da Computação
    

> **Não é necessário estudar todos esses conteúdos.** Eles ficam disponíveis para aprofundamento conforme a necessidade.

# 🔐 Relação com Cyber Security

A matemática necessária para Cyber Security depende bastante da especialização.

Por exemplo, para aprofundar em **criptografia**, determinados conceitos matemáticos são mais relevantes:

```text
Teoria dos Números
        ↓
Divisibilidade
        ↓
Números Primos
        ↓
Aritmética Modular
        ↓
Criptografia
        ↓
RSA / ECC / outros algoritmos
```

Já para outras áreas:

```text
Matemática Discreta
        ↓
Grafos
        ↓
Teoria dos Grafos
        ↓
Redes / Algoritmos / Estruturas
```

E:

```text
Álgebra Linear
        ↓
Vetores + Matrizes
        ↓
Machine Learning / IA
```

# 🧭 Como utilizar esta seção

Não tratar esses conteúdos como uma lista obrigatória.

A estratégia recomendada é:

> **Estudar conforme a necessidade ou interesse.**

### Exemplo — interesse em criptografia

```text
Interesse em Criptografia
        ↓
Teoria dos Números
        ↓
Aritmética Modular
        ↓
Criptografia
```

Nesse caso, não existe necessidade de estudar Álgebra Linear inteira primeiro.

### Exemplo — interesse em Machine Learning

```text
Interesse em Machine Learning
        ↓
Vetores
        ↓
Matrizes
        ↓
Álgebra Linear
        ↓
Machine Learning
```

Nesse cenário, Álgebra Linear passa a ter prioridade maior.

# 💡 Filosofia

> **Conhecimento complementar não significa conteúdo obrigatório.**

O objetivo desta seção é manter uma coleção de assuntos que podem ampliar a visão sobre Computação.

Não é necessário dominar toda a matemática existente para programar, trabalhar com Linux, redes ou Cyber Security.

Entretanto, estudar determinados fundamentos matemáticos pode permitir compreender melhor **como os algoritmos e tecnologias funcionam internamente**, em vez de apenas utilizá-los.

> **Aprender quando houver motivo para aprender.**
